🥇 方式 A：Vercel（推荐）
───────────────────────────
1. 浏览器打开 https://vercel.com
2. Sign in with GitHub
3. Import Project → 选 robot-grinding-knowledge
4. ⚠️ 关键设置：
   Root Directory  → 填  web
   Framework       → 选  Other
   Build Command   → 留空
   Output Dir      → 留空
5. 点 Deploy
6. 得到地址后运行：python deploy_tools/generate_qr.py <你的地址>
7. 二维码在 deploy_tools/qr_defense.png

🥈 方式 B：GitHub Pages（自动）
───────────────────────────
1. 把代码推到 GitHub main 分支
2. GitHub Actions 自动部署
3. 地址：https://xuyai9299-star.github.io/robot-grinding-knowledge/
4. 二维码已生成：deploy_tools/qr_github_pages.png

🛡️ 答辩保命方案
───────────────────────────
主方案：Vercel/Pages 公网 + 二维码
备选1：本地 python pipeline_server.py → 投屏
备选2：PPT 截图（10 个核心页面）
