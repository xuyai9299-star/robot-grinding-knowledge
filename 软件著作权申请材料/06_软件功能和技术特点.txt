  六、软件功能和技术特点
═══════════════════════════════════════

a. 硬件环境：
   开发环境：普通PC，Intel Core i5及以上处理器，8GB及以上内存，500GB硬盘
   运行环境：普通PC或服务器，Intel Core i3及以上处理器，4GB及以上内存，
            50MB可用硬盘空间，需互联网连接（用于调用OpenAlex API和百炼API）

b. 软件环境：
   开发环境：
     - 操作系统：Windows 10/11 64位
     - 运行平台：Python 3.10及以上
     - Web框架：Flask 3.0
     - 向量数据库：ChromaDB 1.5
     - 前端浏览器：Chrome/Firefox/Edge（支持ES6和WebGL）

   运行环境：
     - 操作系统：Windows 10/11、macOS、Linux
     - Python 3.10及以上，需安装依赖包（见requirements.txt）
     - 现代浏览器（Chrome 90+ / Firefox 90+ / Edge 90+）

c. 编程语言：
   Python 3.x（后端业务逻辑、数据处理、API服务）
   JavaScript（前端交互逻辑、3D可视化）
   HTML5 / CSS3（前端页面结构与样式）

d. 源程序量：
   Python：约 3,200 行（20个源文件）
   JavaScript：约 1,100 行（4个业务JS文件）
   HTML/CSS：约 1,200 行（10个页面文件 + 样式表）
   ─────────────────────────────
   总计：约 5,500 行业务代码（不含第三方开源库如D3.js、Three.js等）

e. 主要功能和技术特点：

   【开发目的】
   本软件面向机器人柔性磨削这一垂直制造领域，旨在解决该领域专业知识高度分散、
   通用大语言模型存在"幻觉"导致专业问答不可靠的痛点。通过构建结构化领域知识库
   并融合检索增强生成（RAG）技术，为科研人员和工程师提供高效、准确的专业知识
   问答服务。

   【面向领域/行业】
   智能制造、机器人加工、航空发动机制造。具体面向机器人柔性磨削/抛光工艺的
   科研文献检索、工艺参数查询、材料对比分析等场景。

   【主要功能】
   （1）知识库构建与管理：支持从Zotero文献管理工具和OpenAlex学术API
       自动采集论文元数据，通过五维分类体系（L1工艺领域→L2工艺方式→L3研究主题
       →L4应用场景→L5加工材料）自动标注组织，形成结构化知识库（收录1247篇论文，
       覆盖80+期刊/会议，时间跨度1988-2026）。
   （2）AI智能搜索与问答：用户输入自然语言问题后，系统通过ChromaDB向量数据库
       进行语义检索，结合五维分类体系进行结构化重排序，最终由百炼千问大模型
      （qwen-plus）生成带论文引用标注的中文回答。
   （3）多维知识可视化：提供D3径向树、vis-network层级导图、ECharts径向树、
       3D知识星系（Three.js）、3D会议地球、横向研究时间轴等6种交互式可视化工具。
   （4）知识库自动更新：一键触发OpenAlex论文爬取、LLM相关性筛选与摘要生成、
       自动分类入库、前端数据重建的全流程自动化管线。
   （5）学术生态数据库：收录80+期刊/会议的论文分布、年份趋势、影响因子等信息，
       以3D地球标注会议举办地。

   【技术特点】
   （1）五维结构化混合检索策略：提出并验证了融合五维分类过滤、语义向量匹配和
       摘要加权重排序的混合检索方法。实验表明，该策略在Recall@5指标上较朴素
       BM25全文检索提升29%，工艺查询类问题提升达61%，MRR提升30%。
   （2）全流程自动化知识库构建管线：从多源数据采集（Zotero+OpenAlex）、LLM
       中文摘要生成、五维自动分类到前端可视化输出，实现一键式可持续增量更新。
   （3）真实向量语义检索：基于百炼text-embedding-v3模型（1024维）将全部论文
       向量化存储至ChromaDB，支持余弦相似度语义匹配，检索层与生成层无缝衔接。
   （4）多技术栈融合可视化：集成D3.js（径向树）、Three.js（3D场景）、
       vis-network（网络图）、ECharts（图表）四种开源可视化库，所有依赖
       本地化部署（零CDN），支持离线使用。
   （5）Server-Sent Events实时推送：知识库更新管线采用SSE技术向前端实时推送
       五步处理进度（爬取→LLM筛选→去重合并→自动分类→重建数据）。
